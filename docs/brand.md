# Identité du produit

Base de la mini charte graphique exigée (1 à 2 pages). Maquettes : Figma « LisLeStart ».

## Nom

LisLeStart : nom original, sans reprise de start.gg, de Riot Games ni d'Epitech.

## Couleurs

| Nom     | Hex       | Usage                  |
| ------- | --------- | ---------------------- |
| Nuit    | `#0F1222` | Fond                   |
| Surface | `#181C30` | Cartes                 |
| Craie   | `#F2F4FA` | Texte principal        |
| Lime    | `#C6F432` | Actions, direct, focus |
| Violet  | `#8B7BFF` | Pronostics             |
| Corail  | `#FF8A65` | Alertes                |

## Typographies

| Police                             | Usage                      |
| ---------------------------------- | -------------------------- |
| Barlow Condensed (gras, capitales) | Titres, scores             |
| Manrope                            | Texte                      |
| JetBrains Mono                     | Chiffres, points, horaires |

## Règles

- Un état n'est jamais porté par la couleur seule : icône et mot l'accompagnent.
- Pas d'argent : points, badges et titres uniquement.
