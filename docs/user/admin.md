# Guide administrateur

À rédiger au fil des sprints, avec des captures. Plan :

1. Déclarer un jeu et ses statistiques
2. Créer un tournoi interne et ses étapes
3. Gérer les inscriptions et le check-in
4. Importer un tournoi start.gg
5. Importer un fichier CSV ou JSON
6. Configurer les pronostics
7. Créer des questions Pick'em
8. Saisir les résultats et trancher les litiges
9. Afficher le dashboard en plein écran
